Agents and Tool Use

A text-only model cannot look things up or take action on its own. Tool use and agent loops let an application connect the model to APIs, databases, code execution, or other software.

Minimal definition

An agent is an LLM-driven loop that can observe, decide, act, and continue until a goal or stop condition is reached.

Tool use vs agents

Tool use

The model selects a function and passes arguments.

Agentic loop

The model repeatedly plans, acts, observes results, and updates its next step.

Main risks

FailureMitigation
Wrong tool choiceBetter routing, tool descriptions, and evals.
Looping without progressStep limits, watchdogs, and progress checks.
Unsafe actionPermissions, approvals, validation, scoped credentials.
Agents are software systems, not just clever prompts. Measure task success and safety together.
