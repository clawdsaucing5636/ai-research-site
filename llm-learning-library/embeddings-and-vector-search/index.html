Semantics

Embeddings and Vector Search

Embeddings place text in a high-dimensional space where related meanings sit near one another. They are foundational for semantic search, retrieval, clustering, and recommendation.

Simple version

An embedding is a numerical coordinate that captures useful relationships between pieces of text.

Where embeddings appear

Inside an LLM

Token IDs are first converted into vectors before the transformer processes them.

In retrieval systems

Separate embedding models map whole chunks or queries to vectors for similarity search.

How vector search works

Embed the query

Turn the question into a vector.

Compare distances

Use cosine similarity or dot product against stored vectors.

Return neighbors

The closest chunks become candidate evidence.

Nearest in vector space is not automatically best. Metadata filters, lexical search, and reranking often improve quality.
