Architecture

Transformers and Attention

Transformers made modern LLMs possible by letting each token selectively attend to others in the sequence while still training efficiently at scale.

Historical payoff

Compared with recurrent models, transformers parallelize better and handle long-range dependencies more effectively.

Self-attention in plain language

For each token, the model computes how much it should care about every other relevant token in the context. It uses query, key, and value projections to weight and combine information dynamically.

Queries

What this token is looking for.

Keys

What each other token offers.

Values

The content passed forward when attention is paid.

Beyond attention

Feed-forward blocks

These add nonlinear transformation and feature refinement after attention mixing.

Residuals and normalization

These stabilize deep training and allow many layers to stack effectively.
