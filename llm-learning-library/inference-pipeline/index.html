Runtime

The Inference Pipeline

Inference is the end-to-end runtime path from assembled prompt to emitted output. Understanding it helps explain latency, streaming behavior, and control knobs.

Pipeline lens

Many quality and performance issues are pipeline problems, not purely model problems.

Step-by-step

1

Prompt assembly

Gather instructions, history, retrieved docs, and tool results.

2

Tokenization

Convert text to token IDs.

3

Prefill

Process the full prompt and build cache state.

4

Decode

Generate one token at a time.

5

Detokenize and validate

Convert tokens back to text or structured outputs.
