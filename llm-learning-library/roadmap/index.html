Integration

Roadmap and Learning Path

The objective is to move from vocabulary to systems thinking. You should finish this library able to reason about models, prompts, retrieval, tools, evaluation, and deployment as one connected stack.

Recommended pace

Concepts first, experiments second, optimization third.

Suggested phases

A

Core mental models

Lessons 1 through 6.

B

Application patterns

Prompting, RAG, and agents.

C

Adaptation and measurement

Training choices and evaluation.

D

Reliability and deployment

Safety, serving, hardware, and optimization.

High-value beginner projects

Prompt lab

Compare zero-shot, few-shot, and structured prompts on one task.

Tiny RAG demo

Index a small document set and inspect retrieval failures manually.

Safe tool-calling assistant

Give the model one harmless tool and study when it uses it well.

Mini eval harness

Create 30–100 examples and compare prompts or models systematically.
