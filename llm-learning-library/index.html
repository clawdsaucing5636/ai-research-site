Mental model

The full stack in one sentence

An LLM is a trained next-token predictor wrapped in a software system that turns text into tokens, processes them with transformer layers, generates outputs through sampling, and becomes useful only when paired with prompts, retrieval, tools, evaluation, and deployment discipline.
