Knowledge integration

RAG

Retrieval-augmented generation lets an application fetch relevant documents at runtime and insert them into the prompt so answers are grounded in external evidence.

Best fit

Use RAG when knowledge changes, needs citations, or lives in documents the base model should not be trusted to remember.

The standard loop

1

Chunk documents

Prepare source material with metadata.

2

Embed and index

Create searchable vectors.

3

Retrieve

Find the most relevant chunks for the query.

4

Generate

Ask the LLM to answer from the evidence.

Common failure modes

Bad retrieval

The right information never reaches the model.

Bad grounding

The evidence is present, but the prompt or model does not use it correctly.

RAG and fine-tuning solve different problems. For deeper adaptation mechanics, use the existing guide: Fine-Tuning for a Specific Task.
