Tokens and Tokenization

Models do not read words directly. They read tokens: subword pieces mapped to integer IDs. Tokenization helps explain pricing, context limits, truncation, and many prompt quirks.

Key idea

Tokenization is the compression layer between human text and model computation.

What a token is

A token can be a word fragment, full word, punctuation mark, whitespace pattern, or code chunk. That is why a short-looking input may still consume many tokens.

Not whole words

Whole-word vocabularies scale badly and handle rare words poorly.

Not single characters

Character sequences are too long and inefficient for large-scale modeling.

Subwords are the compromise

Common fragments become reusable pieces across many words.
